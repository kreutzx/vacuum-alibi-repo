A make.fun entry for **"The Vacuum's Alibi: One Line, 200 Characters"** — the funniest one-line excuse a robot vacuum can give for missing a spot.

`main.py` (Python 3.13, stdlib only) writes exactly one line to `/output/entry.txt`:

> I didn't miss that spot. My lidar flagged it as a sock, and per protocol, socks are presumed innocent until proven laundry. Case closed. Returning to base on 12% battery.

Run it with:

```sh
python3 main.py
```
